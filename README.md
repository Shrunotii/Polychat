# PolyChat 

PolyChat is a multilingual chat application with an integrated voice assistant that enables users to send, receive, translate, and listen to messages in multiple languages.

The project combines a web-based chat application with a Python voice assistant to provide hands-free and multilingual communication.

## Features

- Send and receive messages through the chat application
- Translate messages into multiple languages
- Voice-based message input using speech recognition
- Text-to-speech support for reading messages aloud
- Simple chatbot responses for common conversations
- Sentiment-based responses using VADER
- Dictionary lookup and translation
- Voice-based web search
- Read and manage unread messages
- Multilingual communication between users

## Supported Languages

PolyChat supports multiple languages, including:

- English
- Hindi
- Marathi
- Kannada
- Gujarati
- Tamil
- Telugu
- Korean
- Japanese
